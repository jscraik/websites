# JSC Brand Assets

This directory documents the durable JSC brand package used by the site and
social profiles.

## Locations

- Public web assets live under `public/brand/`.
- The live browser favicon is `public/favicon.svg`.
- CSS and JSON design tokens live under `src/styles/brand-tokens.*`.
- Social-safe usage guidance lives in
  `docs/brand/jsc-brand-guidelines-social-safe.md`.

## Ingestion Notes

The original export folder was intentionally flattened into repo-owned
locations. Do not reintroduce wrapper export folders, `.DS_Store` files, or
temporary render outputs as source.
